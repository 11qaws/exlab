# Ex Lab / Race

Ex Lab의 독립형 Race 게임입니다. 전체 명단을 먼저 입력하고 조당 최대 10명으로 균형 편성한 뒤, 선택한 조의 마블이 같은 높이에서 동시에 출발해 물리 코스를 통과합니다.

현재 배포 버전은 `1.1.3`입니다. 고정 코스 안에서 회전막대, 막대형 능동 범퍼, 횡풍, 혼합 구간, 재질 계수를 경기 시드로 바꾸되 같은 시드는 완전히 같은 경기를 재생합니다.

## 구현 범위

- 전체 명단 최대 320명, 조당 2~10명
- 전체 인원에 맞춘 최소 조 수 자동 보정과 더 작은 조 선택
- 동일 이름 기본 미허용, 운영자 옵션으로 별도 참가 허용
- 1명 이상 N명 당첨 설정과 N번째 실제 완주까지 경기 유지
- N번째 당첨자 도착 후 결과표를 열되 미도착 순위는 공란으로 두고, 전체 물리 프레임을 계속 재생하며 도착 순서대로 실시간 입력
- 결과 선확정형과 물리 결과형 선택
- 시드 기반 Matter.js 물리 시뮬레이션
- 기존 물리 속도와 장애물 크기를 유지한 채 세로 길이를 13,500px로 확장한 약 30초 코스
- 경기 구간 폭 366~774px, 중심선 x=250~660의 10개 직선 구간과 좌우 이동량이 커진 9개 S자 전환부, 4개 360° 회전 장치
- 25% 단위로 `PIN DROP → BUMPER RUN → SQUEEZE GATES → FINAL MIX`의 장애물 밀도와 구성을 바꾸고 구간 경계를 경기 화면과 미리보기에 표시
- 일반 막대형 능동 범퍼 6개와 결승 진입 좌우 점프 범퍼 2개가 충돌 공을 위·안쪽으로 튕기며, 실제 충돌 지점에는 짧은 섬광을 표시
- 결승 범퍼의 바깥 끝은 벽 외측까지 겹쳐 공이 범퍼 바깥쪽 주머니에 끼이는 경로를 차단
- `npm run benchmark:obstacles`로 동일 24경기의 접촉률과 0–25 / 25–50 / 50–75 / 75–100% 구간별 역전을 재현 가능하게 측정
- 선두와 360px 이상 벌어진 공만 물리 거리에 비례해 최대 1,350px까지 점진 가속하는 공통 추격 규칙
- 핀·섬·선반·회전 바는 직선 구간에만 배치하고, 모든 경기용 직선 구간의 좌·우 벽에 최소 1개씩 중앙 유도 디플렉터가 있는지 자동 검증
- 결승 진입부는 왼쪽 벽 옆의 120px 회전 막대를 통과한 뒤 내부 폭 60px로 수축하며, 좁은 통로 안에서 결승선을 통과
- 결승 입구 회전 막대는 위쪽 접촉면이 항상 인접 벽을 향하도록 회전 방향까지 자동 검증
- 60px 결승 통로는 물리적 폐색을 막기 위해 양측 벽 장애물 규칙에서 제외하고, 바로 앞 결승 관문 구간에서 양쪽 벽 주행선을 차단
- 모든 독립 충돌체 사이에 공 지름 30px보다 넓은 36px 최소 통과 폭을 강제하는 코스 검증기
- 회전 막대는 전체 회전 반경 대신 중심축에 반지름 15px 공 하나가 놓인 것으로 검사하며, 회전 팔이 주변 오브젝트 가까이 지나가는 것은 허용
- 동일 경기 재생, 새 경기 생성, 최근 결과 20개 로컬 저장
- 데스크톱 전체 순위와 모바일 상위 3명 실시간 순위
- 세로 가속도를 적용한 선두 추적 카메라, 0.5초 선두 변경 확인, 카운트다운, 효과음, reduced-motion 대응
- `3 → 2 → 1 → GO` 출발과 시드 기반 회전막대 시작각·방향·속도, 횡풍 3회, 혼합 힘장 2곳
- 준비 화면에서 실제 물리 프레임을 10초씩 재생하고 매 회차 경기 시드·출발 배치 시드를 모두 새로 만드는 자동 미리보기
- 이름이나 당첨자와 무관한 경기 단위 물리 변형 및 결과 화면 변형 코드
- 준비·생성·방송 대기·경기·결과·오류 상태를 분리한 독립 실행 흐름

## 결과 선확정형의 원칙

결과를 먼저 정하는 모드에서도 경기 도중 특정 마블을 밀거나 이름을 바꾸지 않습니다.

1. 결과 시드로 참가자 순위를 먼저 잠급니다.
2. 별도의 물리 시드로 익명 슬롯들의 경기 궤적과 순위를 만듭니다.
3. 잠근 참가자 순서를 물리 슬롯 순서에 한 번만 배정합니다.
4. 배정 이후에는 물리 궤적을 그대로 재생합니다.

따라서 화면에 보이는 마블은 실제 물리 시뮬레이션을 따르며, 중간 보정은 없습니다.

## 현재 알려진 설계 쟁점

오브젝트 사이의 끼임 통로는 최소 폭 검사로 차단했습니다. 범퍼를 포함한 모든 독립 충돌체와 결승 좌우 범퍼 구성도 같은 맵 검사에 포함합니다. 장시간 정체와 선두 독주에는 이름·당첨 정보가 아닌 현재 물리 거리만 사용하는 공통 규칙을 적용하며, 설정한 N명이 실제 결승선을 통과하지 못하면 추정 당첨자를 만들지 않고 경기 준비 오류로 처리합니다.

자세한 테스트 결과와 설계 결정은 [DESIGN_FINDINGS.md](./DESIGN_FINDINGS.md), 18개 무작위성 후보와 적용 기준은 [GAMEPLAY_VARIATION_DESIGN.md](./GAMEPLAY_VARIATION_DESIGN.md), 전체 명단·조 편성·풀 패키지 계약은 [EX_LAB_RACE_SYSTEM_SPEC.md](./EX_LAB_RACE_SYSTEM_SPEC.md)를 참고하세요.
