# Marble Showdown

레또룰렛과 분리해 검증하는 독립형 마블 레이스 게임입니다. 참가자 2~10명의 명단을 입력하고, 같은 높이에서 동시에 출발한 마블이 물리 코스를 통과하는 경기를 진행합니다.

## 구현 범위

- 참가자 2~10명 입력, 중복 이름을 별도 참가자로 유지
- 11명 이상 입력 시 초과 항목을 보존한 채 경기 시작 차단
- 결과 선확정형과 물리 결과형 선택
- 시드 기반 Matter.js 물리 시뮬레이션
- 동일 경기 재생, 새 경기 생성, 최근 결과 20개 로컬 저장
- 데스크톱 전체 순위와 모바일 상위 3명 실시간 순위
- 자동 카메라, 카운트다운, 효과음, reduced-motion 대응
- 준비·경기·결과·오류 상태를 분리한 독립 실행 흐름

## 결과 선확정형의 원칙

결과를 먼저 정하는 모드에서도 경기 도중 특정 마블을 밀거나 이름을 바꾸지 않습니다.

1. 결과 시드로 참가자 순위를 먼저 잠급니다.
2. 별도의 물리 시드로 익명 슬롯들의 경기 궤적과 순위를 만듭니다.
3. 잠근 참가자 순서를 물리 슬롯 순서에 한 번만 배정합니다.
4. 배정 이후에는 물리 궤적을 그대로 재생합니다.

따라서 화면에 보이는 마블은 실제 물리 시뮬레이션을 따르며, 중간 보정은 없습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

검증:

```bash
npm run lint
npx tsc --noEmit
npm test
```

## 현재 알려진 설계 쟁점

코스에서 마블이 장애물 사이에 정체될 수 있습니다. 52초 제한 안에 전원이 결승선을 통과하지 못하면 완주자는 결승 통과 순서, 미완주자는 제한 시점의 진행 거리로 최종 순위를 정합니다. 결과 화면의 `실행 정보`에 물리 완주 인원과 제한 시간 적용 여부를 표시합니다.

자세한 테스트 결과와 다음 설계 결정은 [DESIGN_FINDINGS.md](./DESIGN_FINDINGS.md)를 참고하세요.
