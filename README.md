# Marble Showdown

레또룰렛과 분리해 검증하는 독립형 마블 레이스 게임입니다. 참가자 2~10명의 명단을 입력하고, 같은 높이에서 동시에 출발한 마블이 물리 코스를 통과하는 경기를 진행합니다.

## 구현 범위

- 참가자 2~10명 입력, 중복 이름을 별도 참가자로 유지
- 11명 이상 입력 시 초과 항목을 보존한 채 경기 시작 차단
- 결과 선확정형과 물리 결과형 선택
- 시드 기반 Matter.js 물리 시뮬레이션
- 폭 740~120px의 10개 직선 구간과 좌우로 이동하는 9개 S자 전환부, 4개 360° 회전 장치로 구성된 약 20초 코스
- 핀·섬·선반·회전 바는 직선 구간에만 배치하고, 벽 부착 디플렉터는 항상 아래쪽 중앙을 향하도록 자동 검증
- 결승 진입부는 420px 회전 관문을 통과한 뒤 96px 폭으로 수축하며, 좁은 통로 안에서 결승선을 통과
- 모든 독립 충돌체 사이에 공 지름 30px보다 넓은 36px 최소 통과 폭을 강제하는 코스 검증기
- 회전 막대는 전체 회전 반경 대신 중심축에 반지름 15px 공 하나가 놓인 것으로 검사하며, 회전 팔이 주변 오브젝트 가까이 지나가는 것은 허용
- 동일 경기 재생, 새 경기 생성, 최근 결과 20개 로컬 저장
- 데스크톱 전체 순위와 모바일 상위 3명 실시간 순위
- 자동 카메라, 카운트다운, 효과음, reduced-motion 대응
- 준비·경기·결과·오류 상태를 분리한 독립 실행 흐름

## 결과 선확정형의 원칙

결과를 먼저 정하는 모드에서도 경기 도중 특정 마블을 밀거나 이름을 바꾸지 않습니다.

1. 결과 시드로 참가자 순위를 먼저 잠급니다.
2. 별도의 물리 시드로 익명 슬롯들의 경기 궤적과 순위를 만듭니다.
3. 잠근 참가자 순서를 물리 슬롯 순서에 한 번만 배정합니다.
4. 배정 이후에는 물리 궤적을 그대로 재생합니다.

따라서 화면에 보이는 마블은 실제 물리 시뮬레이션을 따르며, 중간 보정은 없습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

검증:

```bash
npm run lint
npx tsc --noEmit
npm test
```

## 현재 알려진 설계 쟁점

오브젝트 사이의 끼임 통로는 최소 폭 검사로 차단했지만, 마블이 장애물 위에서 균형을 이루거나 다른 마블과 오래 충돌해 제한 시간까지 남는 경우는 여전히 가능합니다. 68초 안에 전원이 결승선을 통과하지 못하면 완주자는 결승 통과 순서, 미완주자는 제한 시점의 진행 거리로 최종 순위를 정합니다. 결과 화면의 `실행 정보`에 물리 완주 인원과 제한 시간 적용 여부를 표시합니다.

자세한 테스트 결과와 다음 설계 결정은 [DESIGN_FINDINGS.md](./DESIGN_FINDINGS.md)를 참고하세요.
